# Railplot · 列车谱

纯前端的列车运行图编辑器。左侧为纵向线路示意，右侧为时间—站位运行图：主线与支线对齐显示，修改到发时刻即可重绘运行、停站和折返线。

## 本地运行

需要 Node.js 22.12+（推荐 Node.js 24）和 npm。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 进行类型检查并构建至 `dist/`，`npm run preview` 预览构建结果。生成的静态文件可部署在任意静态站点服务器；无后端和账户要求，使用系统字体，不请求远程字体或地图。

## 使用

- 点击运行线或列车列表选择列车，编辑车次、分组、颜色、到发站点与时刻；再次点击已选中的车次或运行线即可取消选择。时刻输入完成后按 Enter 或移出输入框生效。到发相同表示通过，不同则绘制水平停站线。
- 选中运行线后，可横向拖动到达／出发点，按分钟吸附；通过点会同时移动到发时刻。拖动不会越过相邻到发时刻，松手后作为一次修改，可撤销；聚焦时间点后也可用左右方向键微调。
- 同一车次可重复经过车站以表达折返。支持复制列车、整趟平移、添加／删除到发站点，以及最多 100 步撤销与重做。
- “编辑线路”默认提供批量建线：粘贴一列站名，或输入 `广州北 → 长岗 → 大田`，自动生成连续连接。按图上从上到下排列，已有站名会复用；为新站选择主线或支线列，已有站点保持原列。预览确认后整次添加，可一步撤销。
- 支线可以从接轨站向下分出，也可以从上方汇入。例如 `大田 → 支站甲 → 支站乙` 和 `支站甲 → 支站乙 → 白云`；两端接轨可输入 `大田 → 新支站 → 白云`。新站自动放在接轨站之间或首尾，避开已有站位。输入倒序、重复或有歧义的站名会提示修正。
- “逐项调整”可编辑车站名称、纵向站位、线路列和连接，也可从接轨站向上／向下延伸或新增支线。第 0 列为主线，第 1–3 列为平行支线。站位表示抽象纵向位置而非公里数。批量建线默认追加，保留旧连接；新建工程后可勾选“替换现有线路”从头建线，有列车时禁止替换。
- “图表设置”修改工程名称、时间窗口、主网格与可选分组。分组用于自定义配色，不预置铁路种类或交路分类。跨日时间写作 `24:00`、`25:00`；不会将倒序时间猜测为次日。
- 有效修改保存在当前浏览器的本地存储中。请用“保存工程”下载 `.railplot` 文件作为可携带的备份，“打开”可恢复该文件。清除浏览器数据会删除本机自动保存。
- “导出图表”生成包含线路、完整运行图、标题与图例的高清 PNG、矢量 PDF 或 SVG。PNG 默认 3×，超长图按浏览器画布尺寸与像素总量上限调整分辨率。导出不受当前列车高亮影响；时间窗口外的线段仍会被裁切。PDF 的线路、网格和文字均为矢量，嵌入中文字体，可选择和搜索文字。
- `⌘/Ctrl+S` 保存工程；焦点不在输入框内时，`⌘/Ctrl+Z` 撤销，`⌘/Ctrl+Shift+Z` 重做。

示例为虚构演示数据。当前版本面向桌面浏览器；小屏可横向滚动图表。暂不计算闭塞、进路或站台冲突，运行线相交不意味着冲突。横向缩放仅影响时间轴，每分钟至少 12 像素，超宽图幅可横向滚动，左侧线路和站间距保持固定。时间标签按可用间距疏排；底部注记与时间轴之间保留间距。极密站位仍需手动调整纵向站位。

## 工程格式

`.railplot` 为 UTF-8 JSON，顶层 `format: "railplot"`、`version: 1`。未来不兼容修改使用新版本号。未知版本和不合法数据会在导入时被拒绝，不替换当前工程。

```json
{
  "format": "railplot",
  "version": 1,
  "name": "示例线路",
  "time": { "start": "00:00", "end": "01:00", "grid": 5 },
  "stations": [
    { "id": "a", "name": "北站", "position": 0, "lane": 0 },
    { "id": "b", "name": "南站", "position": 20, "lane": 0 }
  ],
  "links": [{ "from": "a", "to": "b" }],
  "groups": [{ "id": "local", "name": "区间", "color": "#587eaf" }],
  "trains": [
    {
      "id": "t1",
      "name": "9702",
      "group": "local",
      "stops": [
        { "station": "a", "arrival": "00:05", "departure": "00:06" },
        { "station": "b", "arrival": "00:15", "departure": "00:15" }
      ]
    }
  ]
}
```

列车的 `group` 为可选字段；工程可没有分组。列车可使用可选的 `color` 覆盖分组颜色。到发站点按行程顺序排列，可跳过通过站；中间未列明的通过时刻按运行图直线表达。支线连接从较小站位指向较大站位，上下行由列车实际访问顺序决定。线路连接用于示意展示，当前不约束列车路径的拓扑可达性。

格式限制：2–60 座车站、0–20 个分组、最多 300 趟列车、每趟 2–200 个到发站点；时刻范围 `00:00`–`71:59`；单图时间窗口不超过 24 小时，主网格 1–60 分钟，文件不超过 5 MB。编辑出现错误时保留最近有效图表，修正之前不会自动保存无效数据。

## 开发

Vue 3 + TypeScript + Vite，Naive UI 提供通用控件，SVG 绘图，Canvas 导出 PNG，按需加载 jsPDF + svg2pdf.js 生成矢量 PDF。中文字体随应用本地提供，导出时按需加载；字体适用独立的 SIL OFL 1.1，详见 `public/fonts/README.md`。

```sh
npm test
npm run build
npm run format:check
```

架构、选型取舍与维护验证见 [架构说明](docs/architecture.md)。
